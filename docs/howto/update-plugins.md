# How to update plugins

## Safe update workflow

1. **Preview changes** — See what would be updated:

   ```
   :Lazy check
   ```

2. **Update all plugins**:

   ```
   :Lazy update
   ```

   This updates every plugin to its latest commit/branch specified in the lazy spec.

3. **Review the changes** — After updating, check for breaking changes:

   ```
   :Lazy log
   ```

   Shows the commit history for the plugin under cursor.

4. **Rollback if needed** — If a plugin breaks, restore the previous lockfile:

   ```sh
   git checkout lazy-lock.json
   ```

   Then run `:Lazy restore`.

## Update specific plugin

```
:Lazy update <plugin-name>
```

Example: `:Lazy update nvim-cmp`

## Sync (re-install all)

If you clone this repo on a new machine:

```
:Lazy sync
```

This installs missing plugins, updates existing ones, and cleans orphaned directories.

## Clean unused plugins

```
:Lazy clean
```

Removes plugin directories that are no longer in your config. Run this after removing a plugin file.

## Lockfile

`lazy-lock.json` pins exact commit versions. It's gitignored and regenerated by Lazy. If you want reproducible installs across machines, remove it from `.gitignore` and commit it.
